## Required Assets

Each presence must include:

<TypeTable
  properties={[
    { name: "logo.png", type: "PNG", description: "Platform brand mark for wider placements, headers, and Open Graph images.", required: true },
    { name: "icon.png", type: "PNG", description: "Compact square icon used in small UI surfaces and Discord activity images.", required: true },
    { name: "thumbnail.jpg", type: "JPG", description: "Marketplace and detail page visual that clearly represents the platform.", required: true }
  ]}
/>

## Logo

Use `logo.png` for the platform brand mark when a wider image is appropriate.

## Icon

Use `icon.png` for compact square displays, colored backgrounds, and Discord activity images.

## Thumbnail

Use `thumbnail.jpg` for marketplace and detail page visuals. It should represent the platform clearly.

## Runtime Asset Constants

The runtime exposes default assets:

```ts
Assets.Logo
Assets.Icon
Assets.Thumbnail
```

Use them in activity payloads:

```ts
await presence.setActivity({
  largeImageKey: Assets.Logo,
  largeImageText: "YouTube",
})
```

## Quality Guidelines

Use a transparent PNG for `icon.png` — Discord renders it on its own background, so a filled background will look wrong. A transparent `logo.png` is preferred but less critical. Keep thumbnails readable at small sizes and avoid generic imagery.
