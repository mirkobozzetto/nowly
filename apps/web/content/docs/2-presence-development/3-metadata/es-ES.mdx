## Campos obligatorios

Cada presence necesita:

<TypeTable
  properties={[
    { name: "name", type: "string", description: "Nombre visible del servicio o plataforma.", required: true },
    { name: "author", type: "object", description: "Autor principal mostrado primero en la biblioteca e imágenes OG.", required: true },
    { name: "description", type: "object", description: "Descripciones cortas localizadas por idioma.", required: true },
    { name: "url", type: "string[]", description: "Dominios o patrones de URL compatibles para la coincidencia de páginas.", required: true },
    { name: "color", type: "string", description: "Color de marca en formato hex, usado por la UI y embeds.", required: true },
    { name: "category", type: "string", description: "Uno de streaming, music, tv, anime u other.", required: true }
  ]}
/>

## Ejemplo

```json
{
  "name": "YouTube",
  "author": {
    "name": "Desarrollador de Nowly",
    "github": "ejemplo"
  },
  "url": ["youtube.com", "www.youtube.com"],
  "color": "#FF0033",
  "category": "streaming",
  "description": {
    "en-US": "Watch and share videos on YouTube."
  }
}
```

## Autor y colaboradores

- `author` — Mantenedor principal, mostrado primero en la biblioteca e imágenes OG.
- `contributors` — Personas adicionales que ayudaron con la presence.

<CalloutInfo>
Los nombres de usuario de GitHub (la clave `github`) se utilizan para resolver avatares.
</CalloutInfo>

## Descripciones y características

- `description` — Texto corto para el mercado, organizado por idioma.
- `longDescription` — Descripción ampliada para páginas de detalle.
- `features` — Lista localizada de comportamientos compatibles (ej. soporte de botones, teclas multimedia).

## Coincidencia de URL

- `url` — Dominios o patrones de URL compatibles para la coincidencia de páginas.
- `regExp` — Coincidencia basada en expresiones regulares para patrones de URL complejos.

<CalloutWarning>
Usa `regExp` solo cuando la coincidencia simple de `url` no sea suficiente. Prefiere listas de dominios explícitas.
</CalloutWarning>

## Categoría

Las categorías permitidas son `streaming`, `music`, `tv`, `anime` y `other`.
