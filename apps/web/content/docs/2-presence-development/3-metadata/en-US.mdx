## Required Fields

Every presence needs:

<TypeTable
  properties={[
    { name: "name", type: "string", description: "Display name of the service or platform.", required: true },
    { name: "author", type: "object", description: "Main author displayed first in the library and OG images.", required: true },
    { name: "description", type: "object", description: "Short localized descriptions keyed by locale.", required: true },
    { name: "url", type: "string[]", description: "Supported domains or URL patterns for matching pages.", required: true },
    { name: "color", type: "string", description: "Brand color in hex format, used by UI and embeds.", required: true },
    { name: "category", type: "string", description: "One of streaming, music, tv, anime, or other.", required: true }
  ]}
/>

## Example

```json
{
  "name": "YouTube",
  "author": {
    "name": "Nowly Developer",
    "github": "example"
  },
  "url": ["youtube.com", "www.youtube.com"],
  "color": "#FF0033",
  "category": "streaming",
  "description": {
    "en-US": "Watch and share videos on YouTube."
  }
}
```

## Author and Contributors

- `author` — Main maintainer, displayed first in the library and OG images.
- `contributors` — Additional people who helped with the presence.

<CalloutInfo>
GitHub usernames (the `github` key) are used to resolve avatars.
</CalloutInfo>

## Descriptions and Features

- `description` — Short marketplace copy, keyed by locale.
- `longDescription` — Expanded description for detail pages.
- `features` — Localized list of supported behavior (e.g., button support, media keys).

## URL Matching

- `url` — Supported domains or URL patterns for matching pages.
- `regExp` — Regex-based matching for complex URL patterns.

<CalloutWarning>
Use `regExp` only when simple `url` matching is not enough. Prefer explicit domain lists.
</CalloutWarning>

## Category

Allowed categories are `streaming`, `music`, `tv`, `anime`, and `other`.
