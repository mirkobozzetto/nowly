## Example

```json
{
  "name": "YouTube",
  "author": {
    "name": "Nowly Developer",
    "github": "example"
  },
  "url": ["youtube.com", "www.youtube.com"],
  "color": "#FF0033",
  "category": "streaming",
  "tags": ["video", "media", "streaming"],
  "description": {
    "en-US": "Watch and share videos on YouTube."
  },
  "assets": {
    "logo": "logo.png",
    "icon": "icon.png",
    "thumbnail": "thumbnail.jpg"
  }
}
```

## Author and Contributors

`author` is the main maintainer and is displayed first. `contributors` are additional people who helped with the presence.

GitHub usernames are used to resolve avatars.

## Descriptions and Features

Use `description` for short marketplace copy. Use `longDescription` for detail pages. Use `features` for a localized list of supported behavior.

## URL Matching

Use `url` for supported domains or URL patterns. Use `regExp` only when simple matching is not enough.

## Category

Allowed categories are `streaming`, `music`, `tv`, `anime`, and `other`.
