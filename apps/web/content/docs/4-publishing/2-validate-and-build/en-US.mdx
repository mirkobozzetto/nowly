---
title: Validate and Build
description: Validate presence metadata and build presence bundles before publishing.
---

## Validate Metadata

Run:

```bash
pnpm presence validate
```

Validation checks `metadata.json` against the Nowly schema. Fix validation errors before building.

## Build All Presences

Run:

```bash
pnpm presence build
```

## Build One Presence

Run:

```bash
pnpm presence build youtube
```

Use the slug or folder-derived name for the target presence.

## Before Publishing

Before pushing a release:

- validate metadata
- build the presence
- test on real supported URLs
- confirm assets render correctly
- confirm settings have safe defaults
