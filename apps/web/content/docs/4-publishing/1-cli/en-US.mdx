## Interactive Mode

Run the CLI without arguments to open an interactive menu:

```bash
pnpm presence
```

## Create a Presence

```bash
pnpm presence init "Netflix"
```

## Build Presences

Build every presence:

```bash
pnpm presence build
```

Build one presence:

```bash
pnpm presence build youtube
```

## Test a Presence Locally

Build the extension with your presences baked in (no server needed):

```bash
pnpm build:extension:dev
```

This builds all presences and bundles them directly into the extension. To test after changes:

1. Edit the presence code (e.g., `packages/websites/src/Y/YouTube/presence.ts`)
2. Rebuild only the changed presence then the extension:

```bash
pnpm presence build youtube
pnpm build:extension:dev
```

3. Reload the extension at `chrome://extensions`
4. The presence is already installed and ready to use

The extension auto-installs bundled presences on startup. No API server, no install page, no Custom API URL needed.

## List Presences

```bash
pnpm presence list
```

## Validate Metadata

```bash
pnpm presence validate
```
