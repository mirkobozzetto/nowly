`1.2.1` est une release de maintenance qui corrige un problème de build où des variables d'environnement de développement fuyaient dans l'artefact Chrome Web Store, et simplifie la surface de configuration de l'API.

<ReleaseTable
  headers={["Zone", "Ce qui change", "Pourquoi c'est utile"]}
  rows={[
    ["Build extension", "Suppression de l'import `dotenv/config` dans le script de build production. Le fichier `.env` n'est plus chargé pendant `build:extension`.", "Les URLs de développement (localhost) étaient publiées sur le Chrome Web Store à la place des URLs de production. Cette correction garantit que l'artefact store utilise toujours `nowly.me`, `api.nowly.me` et `cdn.nowly.me`."],
    ["Environnement API", "Suppression des vars d'env `AWS_SESSION_TOKEN`, `AWS_SES_CONFIGURATION_SET`, `AWS_SES_BASE_URL`. Changement de la région par défaut `AWS_REGION` à `us-east-1`.", "Moins de vars d'env à configurer. Les valeurs par défaut du SDK suffisent."],
    ["Configuration email", "Les vars `SUPPORT_EMAIL_FROM` et `SUPPORT_EMAIL_REPLY_TO` sont maintenant des constantes.", "Plus besoin de les configurer — elles ne changent jamais entre environnements."],
    ["Fiabilité des tests", "Ajout de `test/setup.ts` pour fournir les vars d'env requises à tous les tests.", "Les tests passent sur CI sans fichier `.env`."],
