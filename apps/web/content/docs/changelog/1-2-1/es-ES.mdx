---
title: 1.2.1
date: 2026-06-25
description: Corrección — eliminación de fugas de variables de entorno de desarrollo en el build de producción y simplificación de la configuración de la API.
---

`1.2.1` es una release de mantenimiento que corrige un problema de build donde las variables de entorno de desarrollo se filtraban en el artefacto de Chrome Web Store, y simplifica la superficie de configuración de la API.

<ReleaseTable
  headers={["Zona", "Qué cambia", "Por qué es útil"]}
  rows={[
    ["Build de extensión", "Se eliminó la importación `dotenv/config` del script de build de producción. El archivo `.env` ya no se carga durante `build:extension`.", "Las URLs de desarrollo (localhost) se estaban publicando en Chrome Web Store en lugar de las URLs de producción. Esta corrección garantiza que el artefacto de la tienda siempre use `nowly.me`, `api.nowly.me` y `cdn.nowly.me`."],
    ["Entorno API", "Se eliminaron las vars de entorno `AWS_SESSION_TOKEN`, `AWS_SES_CONFIGURATION_SET`, `AWS_SES_BASE_URL`. Se cambió la región predeterminada `AWS_REGION` a `us-east-1`.", "Menos vars de entorno para configurar. Los valores predeterminados del SDK funcionan sin valores explícitos."],
    ["Configuración de email", "Las vars `SUPPORT_EMAIL_FROM` y `SUPPORT_EMAIL_REPLY_TO` ahora son constantes.", "No es necesario configurarlas — nunca cambian entre entornos."],
    ["Fiabilidad de tests", "Se agregó `test/setup.ts` para proporcionar las vars de entorno requeridas a todos los tests.", "Los tests pasan en CI sin un archivo `.env`."],
  ]}
/>
