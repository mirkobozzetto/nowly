## Cuándo importan los iFrames

Algunos sitios web renderizan reproductores multimedia o estado importante dentro de iframes. Un script de presence normal puede no poder leer todo desde la página de nivel superior.

## Evento de datos de iFrame

La API de Presence expone un evento `iFrameData` para integraciones que necesitan comunicación a nivel de marco.

```ts filename="presence.ts"
presence.on("iFrameData", async (...args) => {
  presence.info("Datos de iframe recibidos")
})
```

## Enfoque recomendado

Usa el manejo de iframes solo cuando la página principal no pueda acceder al estado requerido.

Prefiere selectores DOM estables, elementos multimedia y estado público de la página antes de añadir lógica de iframes.

## Seguridad

Evita recopilar datos personales o sensibles de los marcos. Una presence solo debe enviar información de actividad que sea útil para Discord Rich Presence.
