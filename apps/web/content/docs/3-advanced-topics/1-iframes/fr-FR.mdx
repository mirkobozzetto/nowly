## Quand les iFrames comptent

Certains sites web affichent des lecteurs multimédias ou un état important dans des iframes. Un script de presence normal peut ne pas pouvoir lire toutes les informations depuis la page de niveau supérieur.

## Événement iFrameData

L'API Presence expose un événement `iFrameData` pour les intégrations nécessitant une communication au niveau du cadre.

```ts filename="presence.ts"
presence.on("iFrameData", async (...args) => {
  presence.info("Données iframe reçues")
})
```

## Approche recommandée

Utilisez la gestion des iframes uniquement lorsque la page principale ne peut pas accéder à l'état requis.

Préférez les sélecteurs DOM stables, les éléments multimédias et l'état public de la page avant d'ajouter de la logique iframe.

## Sécurité

Évitez de collecter des données personnelles ou sensibles depuis les cadres. Une presence ne doit envoyer que des informations d'activité utiles pour Discord Rich Presence.
