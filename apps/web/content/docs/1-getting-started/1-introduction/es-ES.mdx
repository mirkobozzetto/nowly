## ¿Qué es Nowly?

Nowly es una aplicación open source de Discord Rich Presence para la web. Detecta actividad en sitios web compatibles y muestra esa actividad en Discord a través de una extensión de navegador, una aplicación host nativa y presences instalables.

## ¿Qué es una Presence?

Una presence es una pequeña integración de JavaScript para un sitio web específico. Se ejecuta cuando un usuario visita una URL compatible, lee el estado útil de la página y envía datos de actividad a Nowly.

Las presences pueden mostrar:

- el nombre de la plataforma
- el vídeo, stream, programa o título de página actual
- nombres del autor, canal o creador
- marcas de tiempo de reproducción
- recursos de la plataforma
- botones que enlazan de vuelta al contenido

## Cómo funciona Nowly

La extensión del navegador detecta sitios web compatibles y carga las presences instaladas. Una presence recopila datos de actividad de la página y envía un payload compatible con Discord.

La aplicación host nativa es el puente local entre el navegador y Discord. Recibe datos de actividad de la extensión y se comunica con el cliente de escritorio de Discord localmente.

## Para quién es esta documentación

Esta documentación es para usuarios que instalan Nowly y desarrolladores que crean presences.

Si solo quieres usar Nowly, comienza con Instalación. Si quieres crear una presence, continúa con Creando tu primera presence después de la configuración.
