## What is Nowly?

Nowly is an open-source Discord Rich Presence app for the web. It detects activity on supported websites and shows that activity in Discord through a browser extension, a native host app, and installable presences.

## What is a Presence?

A presence is a small JavaScript integration for a specific website. It runs when a user visits a supported URL, reads useful page state, and sends activity data to Nowly.

Presences can display:

- the platform name
- the current video, stream, show, or page title
- author, channel, or creator names
- playback timestamps
- platform assets
- buttons that link back to content

## How Nowly Works

The browser extension detects supported websites and loads installed presences. A presence gathers activity data from the page and sends a Discord-compatible payload.

The native host app is the local bridge between the browser and Discord. It receives activity data from the extension and communicates with the Discord desktop client locally.

## Who This Documentation Is For

This documentation is for users installing Nowly and developers building presences.

If you only want to use Nowly, start with Installation. If you want to build a presence, continue to Creating Your First Presence after setup.
