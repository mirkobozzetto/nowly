## Descripción general

Nowly requiere dos partes:

- la extensión del navegador
- la aplicación host nativa

La extensión detecta la actividad del sitio web. La aplicación host conecta esa actividad a Discord.

## Requisitos

Antes de instalar Nowly, asegúrate de tener:

- un navegador basado en Chromium
- la aplicación de escritorio de Discord instalada y ejecutándose
- la extensión de navegador de Nowly
- la aplicación host de Nowly para tu sistema operativo

## Instalar la extensión del navegador

Instala la extensión de Nowly ([Chrome Web Store](https://github.com/q-kimi/nowly/releases) — actualmente en revisión, o cárgala sin empaquetar para desarrollo). Después de la instalación, recarga cualquier página de Nowly abierta para que el sitio web pueda detectar la extensión.

## Instalar el host nativo

Descarga la aplicación host desde la [página de Host de Nowly](/host). Elige el paquete para tu plataforma:

- Windows
- macOS
- Linux

La aplicación host debe estar instalada en el mismo equipo que Discord.

## Confirmar la instalación

Instala una presence, abre un sitio web compatible y verifica Discord. Si la extensión y el host están conectados, tu estado de Discord debería actualizarse automáticamente.

<CalloutInfo>
Si Discord no se actualiza, abre primero el panel de la extensión. Generalmente muestra si falta la extensión, el host o la presence instalada.
</CalloutInfo>
