## Overview

Nowly requires two parts:

- the browser extension
- the native host app

The extension detects website activity. The host app connects that activity to Discord.

## Requirements

Before installing Nowly, make sure you have:

- a Chromium-based browser
- Discord desktop app installed and running
- the Nowly browser extension
- the Nowly host app for your operating system

## Install the Browser Extension

Install the Nowly extension ([Chrome Web Store](https://github.com/q-kimi/nowly) — currently under review, or load unpacked for development). After installation, reload any open Nowly pages so the website can detect the extension.

## Install the Native Host

Download the host app from the [Nowly Host page](/host). Choose the package for your platform:

- Windows
- macOS
- Linux

The host app must be installed on the same machine as Discord.

## Confirm Installation

Install a presence, open a supported website, and check Discord. If the extension and host are connected, your Discord status should update automatically.

<CalloutInfo>
If Discord does not update, open the extension panel first. It usually shows whether the extension, host, or installed presence is missing.
</CalloutInfo>
