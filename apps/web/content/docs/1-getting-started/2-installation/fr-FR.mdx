## Aperçu

Nowly nécessite deux parties&nbsp;:

- l'extension navigateur
- l'application hôte native

L'extension détecte l'activité du site web. L'application hôte connecte cette activité à Discord.

## Prérequis

Avant d'installer Nowly, assurez-vous de disposer&nbsp;:

- d'un navigateur basé sur Chromium
- de l'application de bureau Discord installée et en cours d'exécution
- de l'extension navigateur Nowly
- de l'application hôte Nowly pour votre système d'exploitation

## Installer l'extension navigateur

Installez l'extension Nowly ([Chrome Web Store](https://github.com/nowly-presence/nowly/releases) — actuellement en cours d'examen, ou chargez-la non empaquetée pour le développement). Après l'installation, rechargez les pages Nowly ouvertes afin que le site web puisse détecter l'extension.

## Installer l'hôte natif

Téléchargez l'application hôte depuis la [page Hôte Nowly](/host). Choisissez le paquet pour votre plateforme&nbsp;:

- Windows
- macOS
- Linux

L'application hôte doit être installée sur le même ordinateur que Discord.

## Confirmer l'installation

Installez une presence, ouvrez un site web pris en charge et vérifiez Discord. Si l'extension et l'hôte sont connectés, votre statut Discord devrait se mettre à jour automatiquement.

<CalloutInfo>
Si Discord ne se met pas à jour, ouvrez d'abord le panneau de l'extension. Il indique généralement si l'extension, l'hôte ou la presence installée est manquant(e).
</CalloutInfo>
