## What Presences Do

Presences are installable website integrations. A presence tells Nowly how to detect activity on one platform, such as YouTube or Twitch.

## Browse the Library

Open the Nowly library and choose a platform. The detail page shows supported URLs, features, author information, version history, install status, ratings, and comments.

## Install a Presence

To install a presence:

1. Open the presence detail page.
2. Click Install.
3. Make sure the browser extension is detected.
4. Visit a supported URL for that platform.

Nowly loads the presence when the current page matches one of its supported URLs.

## Update a Presence

When a new version is available, the detail page can show an update action. Updating keeps your installed bundle aligned with the latest signed release.

## Remove a Presence

You can uninstall a presence from its detail page or from the extension interface. Removing it stops Nowly from running that integration on matching websites.
