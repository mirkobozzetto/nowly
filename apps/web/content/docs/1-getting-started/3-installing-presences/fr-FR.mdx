## Que font les presences

Les presences sont des intégrations de sites web installables. Une presence indique à Nowly comment détecter l'activité sur une plateforme, comme YouTube ou Twitch.

## Parcourir la bibliothèque

Ouvrez la bibliothèque Nowly et choisissez une plateforme. La page de détail affiche les URL prises en charge, les fonctionnalités, les informations sur l'auteur, l'historique des versions, le statut d'installation, les évaluations et les commentaires.

## Installer une presence

Pour installer une presence&nbsp;:

1. Ouvrez la page de détail de la presence.
2. Cliquez sur Installer.
3. Assurez-vous que l'extension navigateur est détectée.
4. Visitez une URL prise en charge pour cette plateforme.

Nowly charge la presence lorsque la page actuelle correspond à l'une de ses URL prises en charge.

## Mettre à jour une presence

Lorsqu'une nouvelle version est disponible, la page de détail peut afficher une action de mise à jour. La mise à jour maintient votre paquet installé aligné avec la dernière version signée.

## Supprimer une presence

Vous pouvez désinstaller une presence depuis sa page de détail ou depuis l'interface de l'extension. La supprimer empêche Nowly d'exécuter cette intégration sur les sites web correspondants.
