## Qué hacen las presences

Las presences son integraciones de sitios web instalables. Una presence le indica a Nowly cómo detectar actividad en una plataforma, como YouTube o Twitch.

## Explorar la biblioteca

Abre la biblioteca de Nowly y elige una plataforma. La página de detalle muestra las URL compatibles, características, información del autor, historial de versiones, estado de instalación, valoraciones y comentarios.

## Instalar una presence

Para instalar una presence:

1. Abre la página de detalle de la presence.
2. Haz clic en Instalar.
3. Asegúrate de que la extensión del navegador esté detectada.
4. Visita una URL compatible para esa plataforma.

Nowly carga la presence cuando la página actual coincide con una de sus URL compatibles.

## Actualizar una presence

Cuando una nueva versión esté disponible, la página de detalle puede mostrar una acción de actualización. Actualizar mantiene tu paquete instalado alineado con la última versión firmada.

## Eliminar una presence

Puedes desinstalar una presence desde su página de detalle o desde la interfaz de la extensión. Eliminarla detiene la ejecución de esa integración en sitios web coincidentes.
